## Integration test

Implement both placeholders in `tests/integration/test_workflow.py`.

1. **Import safety.** Start a fresh Python process with an empty temporary working
   directory. Import `highrev`, `highrev.data_processing`, `highrev.modeling`,
   `highrev.runner`, and `highrev.__main__`. It must exit successfully without CSV inputs,
   training output, or creating a model. A fresh process avoids Python's import cache
   hiding side effects. An empty directory alone cannot prove that no computation ran;
   review the module top levels as well.
2. **Explicit execution.** Create `data/01_raw/` inside pytest's `tmp_path`, copy the two
   existing project CSVs there, then invoke the environment's interpreter with `-m highrev`
   and the temporary root as its working directory. Locate the source CSVs relative to
   the test file before changing working directory. Use `sys.executable` so the child
   process uses the same interpreter. Require a successful exit, all three labeled
   metrics, and a nonempty `model.pickle` in the temporary root. Check that parsed metric
   values are finite and lie in their allowed ranges. Restore no global cwd when a
   subprocess's `cwd` argument suffices.
3. **Artifact usability.** Load the model generated by that test and call its prediction
   method on suitable held-out feature rows. Require the expected output shape and finite
   probabilities. This also checks that the extracted categorical helper can be found
   when the pickle is loaded by another process. Load only your own generated artifact.
4. **Behavior preservation.** Compare the new command with `baseline.py` using identical
   raw data, locked environment, random state, test size, and classifier settings. Record
   your own baseline metrics before choosing numerical comparison tolerances. Printed
   three-decimal agreement is a smoke check; focused feature tests protect behavior that
   rounding can hide. Do not copy a universal expected AUC from an old slide.

Unit tests should finish quickly using tiny fixtures. Full raw-data training belongs in
the separately invoked integration suite. Mark a remote workflow result unverified until
you have actually opened its run log; local tests prove only the local path.
